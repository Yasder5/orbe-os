# Raccourcis clavier d'Orbe OS

Super est la touche Windows. Sur un clavier AZERTY, les chiffres des espaces de travail sont les touches de la rangée du haut (& é " ' ( - è _ ç), sans Maj : Orbe les reconnaît par leur position.

Source : `packages/orbe-desktop/binds.lua`. Tout ce qui est marqué « à venir » arrive avec Orbe Shell (étapes 3 et 4).

## Applications

| Raccourci | Action |
|---|---|
| Super + Entrée | Terminal |
| Super + E | Fichiers |
| Super (seul) | Lanceur d'applications : `>` commande, `=` calcul, `:` émoji, `/` actions, `~` fichiers |
| Super + V | Historique du presse-papiers (à venir) |
| Super + D | Tableau de bord (à venir) |
| Super + Maj + : | Aide des raccourcis (à venir ; Super + / sur un clavier QWERTY) |

## Fenêtres

| Raccourci | Action |
|---|---|
| Super + Q | Fermer la fenêtre |
| Super + F | Plein écran |
| Super + Espace | Fenêtre flottante ou en mosaïque |
| Super + J | Changer le sens de la découpe |
| Super + flèches | Passer à la fenêtre voisine |
| Super + clic gauche | Déplacer la fenêtre |
| Super + clic droit | Redimensionner la fenêtre |

## Espaces de travail

| Raccourci | Action |
|---|---|
| Super + 1 à 9 | Aller à l'espace de travail |
| Super + Maj + 1 à 9 | Y envoyer la fenêtre active |
| Super + molette | Espace suivant ou précédent |
| Trois doigts à l'horizontale | Espace suivant ou précédent (pavé tactile) |

## Système

| Raccourci | Action |
|---|---|
| Super + Maj + S | Capturer une zone (presse-papiers et ~/Images/Captures) |
| Super + L | Verrouiller (à venir) |
| Super + Échap | Menu de session (verrouiller, veille, redémarrer, éteindre) |
| Super + N | Centre de notifications |
| Super + Maj + M | Quitter la session immédiatement (secours) |
| Touches multimédia | Volume, micro, luminosité, lecture (aussi écran verrouillé), avec jauge à l'écran |
| Verr. Maj | Indicateur à l'écran |
